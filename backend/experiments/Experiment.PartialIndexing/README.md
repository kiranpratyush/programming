# Experiment.PartialIndexing

A small, asset-free Godot 4 C# animation that explains database partial indexes.

## Run

1. Install the .NET SDK 8 or later.
2. Open this folder in the .NET/C# edition of Godot 4.7.2.
3. Press **F6** or **Run Project**.

The 25-second animation loops automatically.

- **Space** — pause/resume
- **R** — replay from the beginning

For automated captures, append `-- --seek=13.0` to start at a specific point
in the timeline.

The project uses only C#, Godot drawing primitives, and Godot's fallback font.
No external assets or plugins are required.

`preview.png` shows the size-comparison moment from the animation.

## Record a video

Godot 4 can export frames through **Movie Maker mode**. Enable Movie Maker in
the editor, choose a movie file in the project settings, and run the project.
